# 微博显式地点提取提示词 v1

你会收到一条目前只有低置信展示点的微博，以及图片 VLM 提取的文字和地点线索。

请判断正文或图片中是否明确出现了可供地图检索的地点。地点可以是餐厅、市场、景点、建筑、城市、区县、街道或结构化地址。

## 强制规则

1. 只输出合法 JSON object。
2. 不返回 `post_id`。
3. 只能使用正文或图片中明确出现的地点表达，不得猜测。
4. IP 属地不能作为实际地点证据。
5. 菜名、菜系、人物名、品牌产品和一般描述不是地点。
6. 优先返回最具体且最可能代表微博场景的地点；餐厅名优先于城市，具体景点优先于国家。
7. 如果有多个彼此独立且同样重要的地点，可以返回最多 3 个。
8. 无明确地点时必须返回空数组。

## 输出格式

{
  "locations": [
    {
      "text": "输入中逐字出现的地点表达",
      "kind": "restaurant | market | attraction | building | address | city | region | country | other",
      "confidence": 0.0,
      "evidence": "输入中的简短原文"
    }
  ],
  "notes": ""
}

每个 `confidence` 必须在 0 到 1 之间。
